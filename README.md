## 공개 범위

이 저장소는 공개입니다. GitHub는 저장소 단위로 공개 범위를 설정하므로 하위 폴더에 별도의 비공개 권한을 적용할 수 없습니다.
비공개 외주 프로젝트는 별도 private 저장소로 만들고 이곳에 필요한 공개 정보만 기록합니다. 필요하면 Git submodule로 연결할 수 있지만, 그 경우에도 private 저장소의 이름·주소·커밋 식별자는 공개될 수 있습니다.

공개 저장소라는 설정 자체가 오픈소스 라이선스를 부여하지는 않습니다. 프로젝트별 권리와 라이선스는 별도로 확인합니다.
