# 포덕(for duck) 기능명세서 v0.1

대상: `B.forduck`의 현재 로컬 데모 · 범위: PRD S-01~S-04

| ID / 기능 | 사용자 역할 | 화면 | 기본 흐름 | 예외 케이스 |
| --- | --- | --- | --- | --- |
| **S-01.1 가입 시작** | 신규 사용자 | 소개 `/intro` → 가입 `/onboarding` | 소개를 확인하거나 건너뛴다 → 언어 선택 → 내국인·외국인 유형 선택 → 프로필 입력 | 언어 또는 가입 유형을 선택하기 전에는 다음 단계가 비활성화된다. 이미 가입한 사용자는 홈으로 이동한다. |
| **S-01.2 프로필 확인** | 신규 내국인·외국인 | 가입 · 프로필 입력 | 이름과 생년월일을 입력한다. 내국인은 화면에 표시된 6자리 데모 코드를 확인한다. 외국인은 여권 또는 외국인등록번호 형식을 확인하고 번호는 마스킹해 저장한다. | 이름 누락, 생년월일·번호 형식 오류, 내국인 인증번호 불일치 시 다음 단계로 진행할 수 없다. 외국인 서류 형식 확인만으로 인증 완료 상태가 되지는 않는다. |
| **S-01.3 동네 설정·완료** | 프로필 입력을 마친 신규 사용자 | 가입 · 동네 설정 → 환영 → 홈 `/` | 현재 위치로 동네를 조회하거나 ‘지역 직접 선택’을 누른다 → 환영 화면에서 ‘시작하기’ → 프로필을 저장하고 홈으로 이동한다. | GPS 권한 거부·조회 실패 시 안내 후 수동 경로로 진행할 수 있다. 로컬 GPS는 옵션을 켜야 하고, 수동 경로는 데모 기본 동네를 적용한다. |
| **S-02.1 생활 정보 검색** | 가입 완료 회원 | 홈 → 통합 검색 `/search` → 정보 나눔 상세 `/info/:id` | 검색어 입력 → 정보 나눔 탭 선택 → 결과의 제목과 본문 확인 | 검색어가 비면 추천 검색어가 표시된다. 결과가 없으면 빈 상태를 보여준다. 미공개 정보 글과 숨김 게시글은 결과에서 제외된다. |
| **S-02.2 질문 등록** | 가입 완료 회원, 필요 시 데모 인증 | 커뮤니티 `/community` → 글쓰기 `/community/new` | 게시판 선택 → 제목·본문 입력 → 사진 선택(선택) → 이용 규칙 확인 체크 → 등록 → 커뮤니티 목록으로 이동 | 인증이 필요한 설정이면 글쓰기 전 인증을 안내한다. 제목 2자·본문 5자 미만 또는 규칙 미확인 시 등록할 수 없다. 사진은 최대 5장, 장당 5MB로 제한한다. 저장 실패 시 안내한다. |
| **S-03.1 상품 탐색** | 구매 희망 회원 | 중고거래 `/market` → 상품 상세 `/market/:id` | 상품을 검색하거나 거리·카테고리로 좁힌다 → 상세에서 가격, 거래 방식, 가격 제안 가능 여부를 확인한다. | 결과가 없으면 빈 상태를 표시한다. 삭제 등으로 상품을 조회할 수 없으면 상세에서 안내한다. 본인 상품은 ‘판매 관리’를 표시한다. |
| **S-03.2 거래 채팅** | 구매 희망 회원, 필요 시 데모 인증 | 상품 상세 → 채팅방 `/chat/:id` | ‘채팅하기’ 선택 → 상품에 연결된 채팅방을 열거나 생성 → 텍스트로 장소와 시간을 조율한다. | 인증이 필요한 설정이면 채팅 진입 전 인증을 안내한다. 공백만 입력한 메시지는 보낼 수 없다. 사진 첨부는 현재 안내만 표시한다. |
| **S-04.1 영상·문장 재생** | 가입 완료 회원 | 한국어 교육 `/edu` | 카페·병원·편의점 영상 중 하나를 재생한다 → 한국어와 발음 표기, 해당 언어 번역 자막을 확인한다 → ‘학습 문장’에서 문장을 눌러 해당 구간부터 재생한다. | 영상 URL이 미등록이면 안내한다. 확보한 대체 MP4는 로컬에서 재생한다. 자막은 사용자가 켜거나 끌 수 있다. |

**데모 범위:** 계정·게시글·채팅은 브라우저에 저장된다. 다른 기기나 상대방과 실시간 동기화되는 흐름은 범위 밖이다. 현재 로컬 번역 API는 연결되지 않아 신규 자동 번역을 전제로 하지 않는다.

**다음 명세에서 확정할 항목:** 실제 인증·권한 기준, 수동 동네 검색, 검색 결과 없음 화면에서 글쓰기로 이어지는 동선, 채팅 전송 실패·재시도와 신고·차단 운영 정책.
