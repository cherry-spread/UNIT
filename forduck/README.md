## 실행

이 폴더에서 아래 명령을 실행한 뒤 http://localhost:8040 을 엽니다.

```sh
python3 tools/serve.py
```

상품·게시글·관리자 화면 등 클라이언트 기능을 확인할 수 있습니다. 원본 URL은 보존하며, 미리보기 서버가 응답하는 JavaScript에서 확보한 외부 이미지 주소를 로컬 주소로 바꿉니다. 외부 웹폰트와 YouTube는 인터넷이 필요합니다. 이 미리보기는 원본 사이트와 다른 브라우저 저장소를 사용합니다.

### 새 사용자 가입 체험

기존 로컬 프로필과 분리해서 체험하려면 `python3 tools/serve.py --port 8041`을 실행하고 시크릿 창에서 http://localhost:8041/ 을 엽니다. 가입을 다시 체험하려면 시크릿 창을 모두 닫은 뒤 새로 엽니다. 서비스 소개 뒤에 언어 선택, 가입 유형 선택, 프로필 입력, 동네 설정, 환영 화면이 이어집니다. 내국인은 화면에 표시된 데모 인증번호를 사용하고, 외국인은 입력한 서류 번호의 형식을 확인합니다. `지역 직접 선택`을 누르면 원본과 동일하게 데모 기본 동네로 진행합니다.

GPS로 동네를 확인하려면 서버 실행 시 `--use-original-geo`를 추가할 수 있습니다. 이 옵션을 켜고 `현재 위치로 설정`을 누르면 동네 조회에 필요한 위도·경도가 원본 포덕 서버로 전달됩니다.

## 아직 확보하지 못한 내용

- 외부 MP4 3개: 서버 응답 `403 Forbidden`. URL과 실패 내역은 `inventory.json`에 기록했습니다.
- 원본 React/TypeScript 소스, package.json, 빌드 설정, Git 이력: 공개 배포 파일에 포함되지 않습니다. 확인한 두 JavaScript source map 경로도 403으로 접근할 수 없었습니다.
- 서버 구현 및 환경변수: 클라이언트에서 `/api/chat`, `/api/translate`, `/api/geo`를 호출하지만 서버 구현은 내려받을 수 없습니다. 로컬 미리보기에서 채팅·번역 API는 501을 반환하며, GPS 동네 조회는 위의 옵션으로 원본 서버에 연결할 수 있습니다.
- 기존 사용자 브라우저의 localStorage: URL 다운로드만으로 읽을 수 없습니다. 현재 배포 코드는 `local` 모드이며 `podeok.v6.*`, `podeok.v1.*` 등의 키로 데이터를 저장합니다. 브라우저별 추가·수정 데이터는 별도로 내보내야 합니다.
- 외부 링크 대상 페이지, YouTube 영상 원본 및 전체 외부 웹폰트는 수집 범위에 포함하지 않았습니다.

## 기존 브라우저 데이터 백업

기존에 사용하던 브라우저에서 원본 사이트를 열고 개발자 도구 Console에서 `tools/export-browser-data.js` 내용을 실행하면 `forduck-browser-backup.json`이 다운로드됩니다. 해당 사이트의 `podeok.*` localStorage 키와 값을 읽어 파일로 저장하며 서버 전송이나 원본 데이터 수정은 하지 않습니다.

이 파일에는 사용자가 작성한 글·채팅·프로필 등이 포함될 수 있으므로 로컬 `browser-backups/` 폴더에 보관합니다. 해당 폴더는 Git 추적에서 제외했습니다. 현재 저장소의 JSON은 이 브라우저 백업을 대신하지 않습니다.

## 기본 데이터 재추출

Node.js와 `acorn`이 필요합니다. `tools/`에서 `npm install`한 뒤 `node extract-seeds.cjs`를 실행합니다. 추출기는 현재 확보한 번들 파일명에 맞춰져 있습니다.

## 복구 범위

배포본과 공개 리소스 보존 및 데모 기본 데이터 추출을 완료한 상태입니다. 원본 개발 프로젝트나 서버를 완전히 복구한 상태는 아닙니다. 원본 소스와 서버 기능 복구에는 Vercel 프로젝트 또는 원 개발 저장소 접근이 필요합니다.
